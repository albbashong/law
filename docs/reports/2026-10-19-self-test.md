## 4. 남은 문제

### 높음
- **H1. 모델 비결정성 — 환각 1건/45회, 불필요한 되묻기 1건/45회.** G11에서 "용적률은 별표 17(용도지역별 용적률)"이라는 잘못된 조문을 1회 생성. G13은 4회 중 1회 지역을 되물음. `REASONING_EFFORT=low`·temperature 0에서도 흔들림.
  - 대책 후보: (a) 런타임에 **답변 인용 검증 단계**를 두어 도구 결과에 없는 조문 번호를 지우거나 다시 묻게 함, (b) 추론 강도 medium 비교 측정, (c) 골든셋 반복 측정을 CI에 넣어 비율 추적.
- **H2. 골든셋이 작고 개발자가 작성.** 15건, 시스템을 보며 만든 정답이라 과적합 위험. 실무자가 만든 질의·정답 30건 이상의 별도 평가셋(held-out)이 필요.

### 중간
- **M0. 브이월드 토지이용계획 API 호출 한도(추정).** 평가 막바지에 토지이용계획 API가 30회 연속 INCORRECT_KEY(주소 검색은 정상) — 개발키 일일 한도 초과로 보임. 이 상태에선 주소만 담긴 질의가 "용도지역을 알려 달라"는 되묻기로 끝남(우아한 실패). → 운영키 발급, PNU별 용도지역 결과 캐시(일 단위) 권장. 주소 질의 5건은 한도 전 3회 평가에서 정상.
- **M1. 조례 별표 3,350건(4.3%) 텍스트 없음.** 그중 도시·군계획 조례의 용도지역 별표가 있는 곳 39곳은 `미확인`(partial)으로 응답(예: 옥천군, 용인시, 화성시, 평택시, 대전광역시). 원인: 첨부 링크가 낡았고 별표·서식 API 검색으로도 못 찾음, HWP 구조 오류 153건, 서버에 파일 없음 191건. → 법제처 문의 또는 HWP 원문 수동 확보, 혹은 ELIS(자치법규정보시스템) 직접 수집 검토.
- **M2. '전남광주통합특별시' 산하 8곳 지역 매칭 실패.** 통합 이후 조례가 아직 통합 명칭으로 정비되지 않았거나 다른 명칭. 현재 해당 지역 질의는 지역 해석 실패로 응답.
- **M3. 표 구조 손실.** HWP 표를 줄 텍스트로 풀어 셀 경계가 사라짐. 별표의 표(예: 거리 기준표, 용적률 표)는 발췌가 읽기 어렵고 수치 대응이 틀릴 수 있음.
- **M4. 위임 관계를 인용으로만 도출.** 법령정보 API의 위임조문(lsDelegated)은 건당 5초·최대 7.8MB라 받지 않음. 하위 법령이 상위 조문을 인용하지 않는 위임은 누락 가능.
- **M5. 근거상태는 '열거 여부'에 그침.** 업종 조건(예: 대기오염물질 배출시설 1~3종 제외), 층수, 거리 기준의 충족 여부는 판정하지 않고 조건으로만 제시(설계 의도). 소비 측(UI·16002)이 이를 최종 판정으로 오해하지 않도록 표기 필요.

### 낮음
- **L1. 2글자 검색어**("공장")는 trigram 한계로 실패 안내만 함.
- **L2. 발췌문 띄어쓰기 잔재**("건 축물") — 고정폭 줄바꿈 원문 탓. 검색은 공백 제거 색인으로 보정됨.
- **L3. 일부 조례 조문 분해 실패** 0.3%(3,876/1,340,676) — 번호 표기가 비표준.
- **L4. 이전 태스크 참조 범위**(프로파일 4.4)를 카드에 밝히지 않음 — 런타임 기본 동작을 따름.
- **L6. 리뷰 보류 Minor:** 브이월드 실패 시 사용자가 준 지역·용도지역으로 폴백 안 함, 용도 사전의 괄호 표기 단어('펜션(숙박)' 등) 일치 불가와 1글자 단어('절','집') 오일치 위험, '2종일반주거'·'경북영천시' 표기 미해석, 설정 매 호출 재파싱, doc.org 인덱스 없음.
- **L5. 브이월드 지목·면적**은 선택 정보 — 실패 시 "지목 미확인"으로 전용허가 안내가 빠질 수 있음.

- **G23** "김해시 계획관리지역 논에 축사 지으려면 어떤 법을 봐야 해?" — 모델이 building_basis 대신 검색 경로로 가서 보전관리지역 별표를 근거로 답함(용도지역 오인). 프롬프트 규칙을 넣었지만 "어떤 법" 표현에서 흔들림.
- **법령명-조문 짝 오류** — G21에서 "건축법 시행령 제84조"(정답: 국토계획법 시행령). 인용 검증은 조문 번호 단위라 법령명이 틀린 짝은 못 잡음 → 검증을 (법령명, 조문) 짝으로 강화 필요.
- **모델 생성 깨짐** — 1차에서 "경삱시"·"숙박싼다" 같은 깨진 인자 1회(G03). 2차에서는 재현 안 됨. 같은 서버에 짧은 질문은 정상.
- 용도목록에서 고를 때 모델 지식에 기댐(카페 → 제1종 근생은 맞게 골랐으나 바닥면적 300㎡ 기준은 도구 조건에 나올 때만 안내).

### 6-1. 남은 문제 1·2 대응 (2026-10-20)

- **G23 경로 이탈** → law_search 가 질의에서 용도지역(zone_map)과 건축물 용도(별표 1 시설명)를 알아보면 `먼저_부를_도구`로 building_basis 를 권함. 반복 7회 모두 building_basis 로 가서 근거상태 정답(이전: 검색 경로로 빠져 보전관리지역 별표 인용).
  남은 것: 모델이 '논'을 지목 '답'으로 넘기지 않아 농지전용허가 근거 누락(재현율 0.5). 도구가 지목 누락을 안내하도록 했지만 7회 모두 재호출하지 않음.
- **법령명-조문 짝 오류** → 런타임 짝 검증(`ANSWER_PAIR_PATTERN`, `ANSWER_PAIR_KEYS=law,article`) 추가. 되돌린 뒤에도 남으면 답변 끝에 "※ 다음 인용은 조회 결과로 확인되지 않았습니다"를 붙임(`ANSWER_UNVERIFIED_TEXT`). 4차 평가에서 G19의 "국토의 계획 및 이용에 관한 법률 제71조"(정답: 시행령 제71조)가 표시됨.
